## 🚀 Featured Projects

<details open>
<summary><b>🌾 AgriShield-AI — Edge-Native Explainable Crop Disease Diagnostic Framework</b></summary>

<br/>

A professional-grade, edge-native agricultural computer vision platform built to diagnose crop pathology in remote, disconnected farms. Combines a lightweight custom CNN, ONNX edge compilation, Grad-CAM explainability, and an interactive diagnostic dashboard — field-tested with real users, not just benchmarked in isolation.

| Category | Detail |
|:--|:--|
| **Stack** | PyTorch, ONNX, FastAPI, Streamlit, Python |
| **Scale** | 123,011 parameters · 480 KB on-disk footprint |
| **Performance** | 4.2 ms/image inference latency (Intel i7 CPU) |
| **Security** | Fully offline edge inference — zero data transmission required in field mode |
| **Impact** | Field-tested with 12 farmers and 2 agriculture students; feedback directly shaped the UI |
| **Repository** | *link pending* |

**Engineering notes:** The core `AgriShieldCNN` uses a 4-stage Conv-BatchNorm-ReLU-MaxPool block with global average pooling and a single dropout layer before classification — deliberately minimal so it compiles to ONNX and runs on low-power hardware without a network connection. Grad-CAM hooks expose *why* the model reached a diagnosis, overlaying a saliency heatmap on the original leaf image so a non-technical user can visually verify the result rather than trust a black box.

</details>

<details>
<summary><b>🧠 ResearchMind AI — Elite AI-Powered Research Assistant Workspace</b></summary>

<br/>

A production-ready, full-stack RAG workspace that lets students and academics upload, question, compare, and synthesize scientific papers with page-level citations and confidence scoring — not just a chatbot wrapper.

| Category | Detail |
|:--|:--|
| **Stack** | React 19, TypeScript 5, FastAPI, PostgreSQL 16, ChromaDB, LangChain |
| **Scale** | Multi-tenant document/user isolation with metadata-filtered vector search |
| **Performance** | 1,000-char semantic chunks with 200-char overlap for context preservation |
| **Security** | Strict tenant isolation via `user_id` / `document_id` metadata filters in ChromaDB |
| **Impact** | Automates literature review, citation generation (APA/MLA/IEEE/Chicago/BibTeX), and research-gap detection |
| **Repository** | [Researchmind-ai](https://github.com/Kaifali786/Researchmind-ai) |

**Engineering notes:** Documents are parsed page-aware via PyMuPDF so every generated answer traces back to an exact page reference. The RAG pipeline runs query embedding → similarity match → cited prompt → LLM answer, with an async SQLAlchemy 2.0 layer backing conversation memory and a Framer Motion-driven glassmorphic frontend on top.

</details>

<details>

| **Impact** | Instantly filters eligible scholarships across CGPA, country, degree level, and field of study |
